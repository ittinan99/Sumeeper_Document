กติกาทั้งหมดยึดตาม `Sumeeper_GDD.md` เป็นหลัก — ถ้าเอกสารนี้ขัดกับ GDD ให้ถือว่า GDD ถูก และแจ้งแก้เอกสารนี้

สถานะ: ครอบคลุมกลุ่มหน้า **Result** แล้ว ส่วนหน้าอื่นอยู่ในรายการท้ายเอกสาร (ยังไม่เขียน)

## 0. หลักร่วมของทุกหน้า Result

ทุกหน้าสรุปผลต้องตอบ 4 คำถามนี้ ตามลำดับความสำคัญ

1. **ได้อะไร** — drop, currency, ความคืบหน้า
2. **เสียอะไร** — HP, STA, วัตถุดิบที่ถูก Eater กิน, ช่องที่ถูก Freezer แช่
3. **อยู่ตรงไหนของเป้าหมาย** — Curse Gauge → curse ถัดไป / Quest checklist / Threat
4. **ต่อไปทำอะไร** — ปุ่มหลักหนึ่งปุ่มที่ชัดเจน

กติกาความยาว: **ยิ่งหน้าจอนั้นเกิดถี่ ยิ่งต้องสั้น**

| หน้า | ความถี่ต่อ run | รูปแบบ |
| --- | --- | --- |
| Combat Result (ลูกน้อง) | หลายสิบครั้ง | overlay สั้น auto-continue |
| Curse Choice | ไม่กี่ครั้งต่อชั้น | หน้าเต็ม ต้องเลือก |
| Combat Result (บอส) | 3 ครั้งต่อ run | หน้าเต็ม |
| Floor Result | ~3–6 ครั้ง | หน้าเต็ม + มีของให้ทำ |
| Run Result | 1 ครั้ง | หน้าเต็ม + มีจังหวะเล่าเป็นช่วง |

**ห้ามมีในทุกหน้า Result** (ระบบถูกถอดออกจากเกมแล้ว): EXP, Level / Level up, และ **Coin ระหว่างอยู่ในดันเจี้ยน** (ในดันเจี้ยนใช้ Fath เท่านั้น — Coin คำนวณตอนจบ run ที่เดียว)

## 1. Combat Result — ชนะ Feast ทั่วไป (Tier 1–4)

**เกิดเมื่อ** : HP ของ Feast ≤ 0 (จากการต่อสู้จริง หรือจาก skip battle)

**แสดง**
- ของที่ได้ : วัตถุดิบ (Meat / Vegie / Spices) และ Fath ที่ drop
- **Curse Gauge +N พร้อมเกจที่วิ่งเข้าหา threshold ถัดไป** — ข้อมูลสำคัญที่สุดของหน้านี้ เพราะเป็นตัวบอกว่าอีกกี่ตัวจะต้องเลือกรับ curse แล้ว Feast ทุกตัวที่เหลือใน run จะแข็งขึ้น (In-run Threat +1)
- HP ผู้เล่นที่เหลือ และจำนวนที่เสียไปในการต่อสู้ครั้งนี้
- ผลของ Ability ที่เพิ่งเกิดและกระทบนอก combat เท่านั้น เช่น ถูก `Eater` กินวัตถุดิบไปกี่ชิ้น, ช่องรอบตัวถูก `Freezer` แช่กี่ช่อง (ต้องบอกที่นี่ เพราะผู้เล่นจะกลับไปเจอผลบนกริดทันที)

**กดได้**
- แตะที่ใดก็ได้ = ข้าม overlay กลับสู่กริดทันที
- ถ้าไม่กด = ปิดเองแล้วกลับสู่กริด

**ไม่ต้องมี** : ปุ่ม Continue/OK แยกต่างหาก, สรุปสถิติการต่อสู้, การสรุป build

**หมายเหตุ** : ถ้าค่าที่ได้ครั้งนี้ทำให้ Curse Gauge ถึง threshold → ไม่กลับสู่กริด แต่เข้าหน้า **Curse Choice** ต่อทันที

---

## 2. Curse Choice

**เกิดเมื่อ** : Curse Gauge ถึง threshold ภายในชั้น

**แสดง**
- Curse 2 ใบให้เลือก 1 (บังคับเลือก ข้ามไม่ได้)
- ผลของแต่ละใบแบบอ่านเข้าใจได้ทันที
- **ผลรวมที่จะเกิดกับ Feast ทั้งชั้นหลังรับ curse** : ตัวคูณ ATK/HP ใหม่ของ Feast และแจ้งเมื่อ curse ใบนี้จะทำให้ครบทุก 2 ใบ (= Feast ได้ +1 action ต่อท้าย sequence)
- **In-run Threat +1** — แสดงเป็นระดับความดุของ Feast ที่จะใช้ไปจนจบ run ไม่ใช่ค่าที่เกี่ยวกับรางวัล (รางวัลมาจาก Pre-run Threat อย่างเดียว)
- รายการ curse ที่รับไปแล้วทั้ง run + คำเตือนว่า **curse ใบนี้จะติดตัวไปจนจบ run ไม่หมดผลเมื่อเปลี่ยนชั้น** — เป็นการตัดสินใจที่ย้อนกลับไม่ได้ ต้องเขียนให้ชัดที่สุดในหน้านี้

**กดได้**
- เลือก curse 1 จาก 2 → รับผลทันที กลับสู่กริด

---

## 3. Combat Result — ชนะบอส (Tier 5)

**เกิดเมื่อ** : HP ของ Feast ระดับ 5 ≤ 0

**แสดง**
- **วัตถุดิบพิเศษ (Special Ingredient)** ที่ได้ — drop แน่นอน 100% จากบอส
  - กรณี Pre-run Threat เท่าเดิมกับที่เคยล้มบอสตัวนี้แล้ว → แสดงว่าไม่ได้รับวัตถุดิบพิเศษครั้งนี้ **(ต้องเคยแจ้งตั้งแต่ก่อนกดเข้า run และย้ำอีกครั้งที่ Pre-Combat แล้ว ห้ามเซอร์ไพรส์ที่หน้านี้)**
- **Quest checklist ที่อัปเดต** เช่น 1/3 → 2/3
- ของที่ได้อื่นๆ : วัตถุดิบ, Fath, Curse Gauge
- ผลที่ตามมา : ชั้นนี้ผ่านแล้ว (ตามเงื่อนไขการผ่านชั้นปัจจุบัน)

**กดได้**
- ปุ่มเดียว : ไปต่อ → เข้า **Floor Result**

---

## 4. Combat Result — Retreat

**เกิดเมื่อ** : กด retreat ใน Pre-Combat สำเร็จ (retreat กดได้เฉพาะ Pre-Combat)

**แสดง** : toast สั้นๆ — STA ที่จ่ายไป และ STA ที่เหลือ

**กดได้** : ไม่มี — กลับสู่กริดอัตโนมัติ

**หมายเหตุ** : Feast ยังอยู่ในช่องเดิมด้วยสถานะเดิม (ไม่เคยเสียเลือด) จึงไม่ต้องแสดงสถานะ HP ของมัน

---

## 5. Floor Result — จบชั้น

**เกิดเมื่อ** : ผ่านเงื่อนไขการผ่านชั้น (ปัจจุบัน = ล้มบอสของชั้นสำเร็จ / อนาคต = ทำ checklist ของ quest ครบ)

หน้านี้ไม่ใช่หน้าโชว์คะแนน แต่เป็น **จุดพักเตรียมตัว** เพราะเป็นจุดที่ระบบรีเซ็ตมากที่สุดใน run

**แสดง — ส่วนปิดลูปชั้นที่ผ่านมา**
- สรุปของชั้น : Feast ที่กำจัดแยกตาม Tier, Fath ที่ได้, วัตถุดิบที่ได้, HP ที่เสียไปทั้งชั้น
- **Curse Gauge รีเซ็ตกลับ 0** — สื่อให้ชัดว่ารีเซ็ตแค่ "เกจ" คือชั้นหน้าจะได้เลือก curse ใหม่อีกชุด ไม่ใช่การล้างคำสาป
- **curse ที่สะสมมาทั้ง run ยังออกฤทธิ์อยู่ทั้งหมด** — แสดงเป็นรายการที่ผู้เล่นกดดูได้ พร้อม In-run Threat และ **ตัวคูณ ATK/HP ปัจจุบันของ Feast** ที่จะพาเข้าชั้นถัดไป (นี่คือข้อมูลที่แพงที่สุดของหน้านี้ เพราะมันคือความยากที่ผู้เล่นสร้างขึ้นเองและกำลังจะเจอต่อ)
- Quest checklist ปัจจุบัน (เหลืออะไรบ้าง)

> ⚠ หน้านี้ **ไม่ใช่จังหวะโล่งอก** อีกต่อไป — เมื่อ curse ไม่หมดผลตอนเปลี่ยนชั้น หน้านี้ทำหน้าที่เป็น "จุดตั้งหลักก่อนเจอของที่หนักขึ้น" ต้องระวังไม่ให้ tone ของหน้า (คำว่า Good job! / เอฟเฟกต์ฉลอง) ขัดกับข้อมูลที่กำลังบอกว่าเกมกำลังยากขึ้น

**แสดง — ส่วนเตรียมชั้นถัดไป**
- สถานะ build ปัจจุบัน : HP/Max HP, STA, Equipment ที่ถืออยู่ (สูงสุด 6), Perk ที่มี, curse ทั้งหมดที่ยังออกฤทธิ์ (ทั้งจาก Contract และที่รับระหว่าง run)
- **Pre-run Threat และตัวคูณ coin ที่จะได้ถ้าออกตอนนี้** (เป็นข้อมูลประกอบการตัดสินใจว่าจะดันต่อหรือถอนตัว — ตัวคูณไม่ขยับตาม curse ที่รับระหว่างทาง จึงต้องไม่ทำให้ผู้เล่นเข้าใจผิดว่าดันต่อแล้วคูณเยอะขึ้น)
- ทรัพยากรที่ถืออยู่ : Fath, วัตถุดิบแยก 3 ชนิด, วัตถุดิบพิเศษที่เก็บได้แล้ว
- **ข้อมูลชั้นถัดไป** : ชื่อ Floor Variant, ธีม Feast ของชั้น และกติกาพิเศษของชั้นนั้น เพื่อให้วางแผน loadout ล่วงหน้าได้

**กดได้**
- **Cook** — เข้าหน้าทำอาหาร (จำเป็นต้องมีที่นี่ เพราะ Meal คือทางฟื้น HP/STA หลัก และ Recipe คือแหล่ง Max HP เดียวของเกม)
- **จัดการ Equipment** — ดู/จัดเรียง/ทิ้งของที่ถืออยู่
- **ลงชั้นถัดไป** (ปุ่มหลัก)
- **ออกจากดันเจี้ยน (Extract)** — จบ run ทันทีโดยได้รางวัลเต็มตามที่เก็บมาได้ ต้องมีป๊อปอัปยืนยัน และต้องบอกยอดที่จะได้รับก่อนยืนยัน พร้อมเตือนถ้ายังมีวัตถุดิบเหลือ (วัตถุดิบไม่แปลงเป็น coin — ควรทำอาหารก่อนออก)

**ไม่ต้องมี** : New Unlocks (เป็นของหน้า Run Result), ยอด Coin, เวลาเป็นตัวเลขเด่น

## 6. Run Result — จบ run

**เกิดเมื่อ** : จบ run ทั้ง 3 ทาง — ส่งคำเรียกร้องสำเร็จ / ออกจากดันเจี้ยนเอง / แพ้ (HP ≤ 0)
ใช้โครงหน้าเดียวกันทั้งสามกรณี ต่างกันที่เนื้อหาบางส่วน (ตารางท้ายหัวข้อ)

หน้านี้เล่นเป็น 4 ช่วง เรียงตามลำดับ และ **ข้ามได้ทุกช่วง**

**ช่วงที่ 1 — คำตัดสิน**
- ผลของ run (สำเร็จ / ออกเอง / แพ้)
- **Quest checklist 3 ช่อง** — ช่องที่ได้แสดงวัตถุดิบพิเศษ + ชื่อบอส, ช่องที่ไม่ได้แสดงเป็นบอสที่ยังไม่ถูกล้ม (นี่คือ objective จริงของ run จึงต้องอยู่บนสุด)
- **Pre-run Threat** ของ run นี้ (ค่าเดียวที่ใช้คูณรางวัล) — ส่วน In-run Threat ที่สะสมมาทั้ง run แสดงเป็นสถิติในช่วงที่ 4 ได้ แต่ **ห้ามวางไว้ในใบเสร็จ** เพราะไม่เข้าสูตรเงิน
- ชั้นที่ไปถึง + ชื่อ Floor Variant

**ช่วงที่ 2 — ใบเสร็จ (Payout Ledger)** — ต้องไล่ทีละบรรทัดตามสูตรใน GDD ไม่ใช่โชว์ยอดรวมทีเดียว เพื่อให้ผู้เล่นเรียนรู้สูตรรางวัลไปในตัว
- coin จากจำนวนวัตถุดิบพิเศษ (0 / 100 / 300 / 500)
- coin จาก Fath ที่เหลือ (1 fath = 10 coin)
- **× ตัวคูณจาก Pre-run Threat** — ตัวคูณเดียวในสูตร ควรเป็นบรรทัดที่เน้นที่สุดของใบเสร็จ
- ยอดรวม coin
- **ไม่มีบรรทัดวัตถุดิบธรรมดา** — วัตถุดิบที่เหลือไม่แปลงเป็น coin แต่หน้านี้ควรแสดงจำนวนที่เหลือติดมือแบบ "ไม่ได้ใช้" เพื่อสอนผู้เล่นว่าครั้งหน้าควรทำอาหารให้หมดก่อนออก

**ช่วงที่ 3 — ความคืบหน้าเมตา**
- สิ่งที่ปลดล็อคได้จาก run นี้ : Recipe ใหม่, Feast ใหม่ใน codex, equipment/character ที่เงื่อนไขครบ
- **แถบความคืบหน้าไปยังของชิ้นถัดไป** (ต้องมีเสมอ ไม่ใช่แสดงเฉพาะของที่ปลดได้แล้ว)
- บันทึก Threat : บอสตัวใดที่ถูกล้มไปแล้วที่ **Pre-run Threat** ระดับนี้ และจะไม่ให้วัตถุดิบพิเศษซ้ำอีกจนกว่าจะเพิ่ม Pre-run Threat (เป็นการ "บันทึกผล" เท่านั้น — การ **แจ้งเตือน** จริงอยู่ที่หน้ารับ quest ก่อนเข้า run ครั้งถัดไป)

**ช่วงที่ 4 — บันทึกการเดินทาง** (พับเก็บได้ ไม่บังคับดู)
- Equipment ที่ใช้ตอนจบ + Tier
- Perk ที่ได้ (Primary / Secondary / Normal)
- Curse จาก Contract ที่รับตอนเริ่ม run และจำนวน curse ที่รับจาก Curse Gauge รวมทั้ง run
- Feast ที่กำจัดแยกตาม Tier
- Meal ที่ทำระหว่าง run
- จำนวนช่องที่เปิด และเวลาที่ใช้ (เวลามาอยู่ตรงนี้ ไม่ใช่จุดเด่นของหน้า)

**กดได้**
- **กลับสู่กิลด์** (ปุ่มหลัก) — รับ coin และไปหน้านอกดันเจี้ยน
- **ลุยอีกรอบ** — เริ่ม run ใหม่ด้วย quest/Threat เดิม
- แตะเพื่อข้ามการเล่นทีละช่วง / กางดูบันทึกการเดินทาง

**ความต่างของแต่ละกรณี**

| | ส่งคำเรียกร้องสำเร็จ | ออกจากดันเจี้ยนเอง | แพ้ (HP ≤ 0) |
| --- | --- | --- | --- |
| บรรทัดเปิด | ชื่อ quest ที่สำเร็จ | quest ที่ยังค้าง | ตายที่ชั้นไหน + Feast ตัวที่ฆ่าเรา |
| coin จากวัตถุดิบพิเศษ | ได้ | ได้ | ได้ (เฉพาะที่เก็บได้แล้ว) |
| coin จาก Fath ที่เหลือ | ได้ | ได้ | **ถูกริบ** — ต้องแสดงเป็นบรรทัดสีเทาให้เห็นว่าเสียอะไรไป |
| นับเป็นส่งคำเรียกร้องสำเร็จ | ใช่ | เฉพาะเมื่อ checklist ครบ | ไม่ แม้เก็บครบ 3 ชิ้น |
| ปุ่มหลัก | กลับสู่กิลด์ | กลับสู่กิลด์ | ลุยอีกรอบ |

## 7. หน้าที่ยังไม่เขียน

- Pre-Combat / Combat (watch-only)
- Shop (Merchef), Forge (Kitchen Smith), Perk (The Seasoned One), Item (Chest + Banish), Hint (Flavour Prophet)
- Cook popup
- Dungeon Grid (HUD ระหว่างสำรวจ)
- หน้ารับ Quest + The Curse Contract (ตั้งค่า Pre-run Threat)
  - ข้อกำหนดที่ล็อกไว้แล้ว : ต้องแสดงบอสทั้งสามตัวของ quest พร้อมป้ายว่าตัวไหน **จะให้ / ไม่ให้วัตถุดิบพิเศษ** ที่ Pre-run Threat ที่ตั้งอยู่ตอนนี้ และป้ายต้องอัปเดตทันทีเมื่อปรับ Contract ขึ้น-ลง (ดูหัวข้อ Threat ใน GDD)
- หน้านอกดันเจี้ยน : กิลด์, unlock, codex
